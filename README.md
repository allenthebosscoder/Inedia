# Inedia

Inedia is a local-first job application toolkit: a Flask/SQLite job tracker paired with a browser extension that autofills application forms.

## Privacy

Profile data, resumes, applications, and browser sessions stay on each user’s computer. Inedia does not require Google authentication or a hosted account. Do not commit personal profiles, resumes, databases, screenshots, or credentials.

## Projects

- `tracker/` — local job tracking, scanning, ranking, and the profile API.
- `extension/` — Chrome extension for local profile management and cautious autofill.

See each project’s documentation for setup. Contributions are welcome; please use fake data in fixtures and examples.
